## 打飞机（index.html）

单文件、零依赖的竖版打飞机小游戏，直接用浏览器打开 `index.html` 就能玩，手机上也能玩。

- 按住鼠标或手指拖动操控飞机，子弹自动连发；方向键 / WASD 也能操控
- 三种敌机：小型机、蛇形机、会开火的坦克机，随关卡逐级增强
- 吃 `P` 提升火力（单发 → 双发 → 三发 → 四发），吃 `S` 获得 3 秒护盾
- 击落计分、每关递增难度、3 条命、最高分保存在 localStorage
- `P` 暂停 / 继续，`M` 静音，`R` 重开
- 按屏幕自适应缩放，手机飞书里打开也不会出现滚动条
